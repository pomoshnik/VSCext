# Дерево конфигурации 1С для VS Code (v0.2)

Мини-платформа в духе 1С:Предприятие:

- **Дерево конфигурации** в левой панели (Справочники, Документы, Регистры, Перечисления…)
- **Хранение метаданных в JSON-файлах** проекта: `metadata/Справочники/Номенклатура.json`
- **Модули бизнес-логики на C#** — `src/BusinessLogic/Modules/*.cs` (ПередЗаписью, ПриЗаписи, ПриЗаполнении)
- **Публикация в SQLite** — кнопка 🗄 запускает `tools/Publisher` (создаёт/обновляет схему `data/app.db`)
- Для просмотра данных — клиент на Avalonia (`client/Client`)

## Работа с деревом

| Действие | Где |
|---|---|
| Добавить / Удалить / Свойства / Публикация | кнопки в заголовке панели |
| Добавить, Открыть модуль (C#), Изменить тип, Переименовать, Удалить, Свойства | контекстное меню ветки |
| Палитра свойств: Имя, Синоним, Комментарий, Тип | команда «Свойства» |

## Проект конфигурации

Откройте папку с каталогом `metadata/` — дерево автоматически загрузится из JSON-файлов,
все изменения сохраняются в файлы (правки файлов снаружи подхватываются автоматически).
В пустой папке выполните команду **«1С: Инициализировать проект конфигурации»** — будет
создана демо-конфигурация.

Без открытой папки расширение работает в демо-режиме (без сохранения).
